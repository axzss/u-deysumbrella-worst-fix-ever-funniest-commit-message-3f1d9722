# Worst Fix Ever: Funniest Commit Message

My commit message for the bug fix that made everything worse:

> fix: infinite loop by adding a second one, for symmetry

The joke is built from the machine's own condition: an infinite loop,
"fixed" by adding a second infinite loop. The repair literally doubles
the disease, and the engineer justifies it with a deadpan aesthetic
excuse — "for symmetry" — faintly proud of the balance. The punch is
the very last word, the kind of thing a tired engineer actually types
at the end of a bad day. No revert, no testing in production, no
breaking everything: the fix is precise, specific, and exactly twice
as bad. On a second read it gets better: the engineer did not fail to
fix the loop, they succeeded at balancing it.

## Run it

```sh
node main.ts
```

Requires Node 22+. Standard library only, no network access. The program
writes exactly the commit message above, with no newline and nothing
else, to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, or
the current directory), and prints it to stdout.
